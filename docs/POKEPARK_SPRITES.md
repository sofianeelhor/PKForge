# Poképark sprite credits and format

Optional walking sprites are downloaded from [PMDCollab / SpriteCollab](https://github.com/PMDCollab/SpriteCollab), the repository behind [PMD Sprite Repository](https://sprites.pmdcollab.org/). Each downloaded sprite retains its original `credits.txt`; `PokeparkSpriteService.GetAttribution` exposes it to the app. `GetSourceUrl` links to the exact asset directory and its credit history. Contributor names and contact links are listed in the repository's [credit_names.txt](https://github.com/PMDCollab/SpriteCollab/blob/master/credit_names.txt).

Community submissions use [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/), as stated in the repository's [submission policy](https://github.com/PMDCollab/SpriteCollab#submission-and-use-policy) and [license](https://github.com/PMDCollab/SpriteCollab/blob/master/LICENSE.md). The repository also contains original CHUNSOFT assets; Pokémon and original game artwork remain the property of their respective owners. Community licensing does not replace those underlying rights. These assets are separate from PKForge source-code licensing. PKForge displays individual frames without editing their pixels, with runtime positioning and scaling.

The [PMD format documentation](https://wiki.pmdo.pmdcollab.org/PMD_Sprite_Format) defines XML animation metadata, horizontal animation frames, vertical direction rows, and durations in 1/60-second ticks. The service reads Walk and Idle (including CopyOf), checks sheet dimensions before decode, and supports one or eight direction rows. Native rows are south, southeast, east, northeast, north, northwest, west, southwest. Missing Idle holds the first walking pose without cycling it.

Base species use `sprite/NNNN/`; shiny base species use `sprite/NNNN/0000/0001/`. PMD form numbers are not assumed to match PKHeX form numbers: all nonzero forms retain the existing bundled sprite. Missing walks, missing shiny variants, network failures, or incomplete credits also retain the bundled sprite; ordinary sprites are never substituted for shiny Pokémon. Gender-specific sheets are not selected by this interface.

Downloads are limited to two simultaneous requests and 24 queued variants. XML/credits are limited to 256 KiB each and images to 2 MiB with a decoded pixel cap. Memory and disk caches each retain at most 64 variants; failed assets retry after five minutes. Cached sprites work offline. Android may reclaim the disk cache.
