# Poképark MPWSP01 assets

The supplied environment artwork is from **MPWSP01** by Scarloxy, the artwork credited by the [clear-code-projects/Python-Monsters README](https://github.com/clear-code-projects/Python-Monsters). The upstream README states that the Python-Monsters code is CC0 and credits the artwork to Scarloxy with the [MPWSP01 itch.io page](https://scarloxy.itch.io/mpwsp01). The downloaded package did not include a separate license file; this attribution is kept with the bundled assets.

Bundled assets currently used by Poképark:

- `background1.png`: grassy forest meadow
- `background2.png`: beach and sea
- `background3.png`: snowy field
- `tileset.png`: environment tiles and props

The assets are used as supplied, with runtime scaling/cropping only. The Pokémon and Pokémon-derived sprites in PKForge remain separately attributed to their own sources.
