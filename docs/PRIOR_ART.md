# PKForge prior-art notes

Status: foundation research, 2026-07-17. PKForge is a clean-room implementation. Reference repositories were read for facts only; no source, class, project layout, or naming is copied.

## API and licensing risks

- The PKHeX checkout used for this foundation is revision `24c9e3c31f9f84ef9fd999a1306a8fb129d4f07e`; API names in the brief are leads, not a contract. The adapter must compile against one pinned revision and expose only our DTOs/interfaces.
- PKHeX.Core is GPLv3-or-later. ALM source/repository evidence includes an MIT license, but the compatible distribution and any combined work need a license review before shipping. This document does not make a legal conclusion.
- PKSafe's Eden/Azahar paths and sprite CDN claims are not independently verified. They remain discovery inputs, not hard-coded truth.
- No reference implementation is copied. PKForge's project structure, names, interfaces, and persistence schema are original.
