# Pokémon Unbound data tables

Species, move, item, and ability tables extracted from the Pokémon Unbound v2.1.1.1
ROM by the PUSE project (https://github.com/Zannael/PUSE), MIT licensed. Vendored
verbatim except movepp.txt, which was generated from PUSE's move_table_from_rom.json
(move id -> base PP only). These are the ROM's own tables: ids and names extend far
beyond retail Gen 3 (species to ~1267, moves to 922, items to 724).
